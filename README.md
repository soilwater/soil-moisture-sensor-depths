# soil-moisture-sensor-depths
This interactive web application allows users to evaluate how different soil moisture sensor depth configurations represent the vertical distribution of soil water and total profile storage. Using gravimetric volumetric water content measured from 1-m in situ soil cores segmented at 5-cm intervals as the reference, the app simulates “perfect” sensor readings at user-selected depths and reconstructs soil moisture profiles using a limited number of sensors. The estimated profile is then compared against the observed core data to quantify errors in mean volumetric water content and profile water storage, providing a tool to assess trade-offs between sensor number and sensor depths.
